C# Calculator (Console Application)

Overview:
This is a simple console-based calculator built using C#. It performs basic arithmetic operations and helps demonstrate fundamental programming concepts like control structures, loops, and user input handling.


Features:
* Addition (+)
* Subtraction (-)
* Multiplication (*)
* Division (/)
* Continuous execution using loop
* Handles division by zero errors


Technologies Used:
* C#
* .NET Console Application


Learning Outcomes:
* Understanding of basic C# syntax
* Working with loops and conditional statements
* Handling user input in console applications
* Basic error handling


Future Improvements:
* Add GUI (Windows Forms / WPF)
* Add advanced operations (power, square root)
* Improve input validation


Note:
This project was created as part of learning and practicing C# fundamentals.
